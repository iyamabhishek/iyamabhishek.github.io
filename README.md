# iyamabhishek.github.io

Personal academic website for Abhishek Kumar — https://iyamabhishek.github.io

Static single-page site (plain HTML/CSS, no build step).

- `index.html` — content (bio, publications, experience, service)
- `style.css` — styling
- `assets/` — profile photo, paper PDFs, figure thumbnails, CV

To edit: change `index.html` / `style.css` and push to `main`. GitHub Pages serves it automatically.
